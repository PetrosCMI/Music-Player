# Web-based audio player called Audio Player

## Requirements
- Version should be displayed in the app title.
- Plays audio files that are local to the device
- Playing is not affected by the state of the screen (on/off).  Specifically if the track has been paused for a time (say 5 or 10mins), resume should still work, even if the display is off.
- Works with bluetooth headsets and speaker
- Maintains a playback list.  One button to add tracks to the list.  One button to clear the playback list. The playback list should be persisted so that next time the app is opened, the list is restored.  The track position within the track should also be persisted.

## Controls
- track position indicator on screen
- playback speed slider on screen with buttons for 0.1 factor adjustments
- play/pause - from screen or from single press on headset
- skip forward 60s - button on screen or double click on headset
- previous track - button on screen or triple click on headset
- no loop, loop 1 track, loop all button on screen
